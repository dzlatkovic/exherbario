# Prepare a results table with an AI assistant

Ex Herbario has no built-in AI. Use the assistant you already have (Claude, ChatGPT or another) to turn a published paper into an import table; every value then goes through the normal preview and compound review.

1. On the study page, open **Add data → Prepare the table from a paper with your AI assistant**. Copy the prompt and download the template.
2. Give the assistant the prompt, the paper's PDF and its supplementary files.
3. Paste its Table A (chromatographic profiles) into the template's *GC-MS profile* sheet, or Table B (isolated compounds) into *Isolated compounds*. Rename the sample columns to your sample codes. Use Section C when creating samples, preparations and run conditions.
4. Import the file and check every value against the paper.

The prompt asks the assistant to copy values exactly as printed, mark trace and not-detected values, leave out summary rows, give each row its source, and give identifiers and SMILES only where the paper prints or draws them.

You remain responsible for the values. Check SMILES written from drawings, and every value the assistant lists as uncertain, with particular care.
